## 📁 DB_Foundation/

This folder contains instructional materials from CS3101 (University of St Andrews), covering relational databases from theory to SQL practice. These are foundational to understanding and extending the Impact Tracker database design.

### Contents

#### ER & Relational Design
- `L02_ER_Model.pdf`: Intro to ER modeling and diagram conventions.
- `L03_Extended_ER_Model.pdf`: Inheritance, generalization, weak entities, and multivalued attributes.
- `L04_Relational_Model.pdf`: Relational algebra, schema definitions, and relational model foundations.
- `L05_ER_to_Relational.pdf`: Mapping from ER models to relational schemas.

#### Normalization & Dependencies
- `L06_Functional_Dependencies.pdf`: Functional dependencies, candidate keys, and schema normalization.

#### SQL and Constraints
- `L08_SQL_Intro.pdf`: SQL basics, SELECT queries, and schema creation.
- `L09_SQL_Aggregates_to_Modification.pdf`: GROUP BY, aggregation, data updates, and subqueries.
- `L10_SQL_Joins_to_Constraints.pdf`: Joins, foreign key constraints, assertions, and relational integrity.

### Learning Objectives

- Model complex data with ER and Extended ER
- Normalize schemas using functional dependencies
- Query relational data with SQL
- Apply constraints for data integrity
